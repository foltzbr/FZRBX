# Security Policy

## Supported Versions
| Version | Supported |
| ------- | --------- |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability
Open a GitHub issue with `security` label. Do not post exploits for active abuse.

Notes:
- front-end only, no server, no data collection
- storage is `chrome.storage.local` only
- visual/educational use only, not affiliated with Roblox
